Stock Move Forced Lot Multi

Force multiple lots from MO to PO through procurement

Overview

This module allows you to define multiple lots on Manufacturing Order components, which are then automatically propagated through procurement to Purchase Orders and their incoming shipments.

Workflow

MO (Manufacturing Order)
  └── stock.move (raw material)
          └── forced_lot_ids = [LOT001, LOT002, LOT003]
                              ↓ procurement (MTO)
PO (Purchase Order)
  └── purchase.order.line
          ├── forced_lot_ids = [LOT001, LOT002, LOT003]
          └── description includes lot names
                              ↓ confirm PO
Picking (incoming)
  └── stock.move
          └── stock.move.line (auto-created)
                  ├── lot_id = LOT001
                  ├── lot_id = LOT002
                  └── lot_id = LOT003

Features

  • Many2many lots on stock moves
  • Automatic propagation through procurement
  • Lot names added to PO line description
  • Auto-creation of move lines per lot on incoming
  • Full MRP integration

Usage

  1. Create a Manufacturing Order
  2. In Components tab, add lots to "Forced Lots" field
  3. Confirm MO - PO is created with lots (if MTO)
  4. Confirm PO - Picking has move lines per lot
