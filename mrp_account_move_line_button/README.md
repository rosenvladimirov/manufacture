# MRP Account Move Line Button

Adds a smart button on the manufacturing order form that opens the debit and
credit journal items of the accounting entries generated by the production, in
the standard `account.view_move_line_tree` list view.

## What it does

This module builds on top of
[`account_move_line_mrp_info`](https://github.com/OCA/manufacture/tree/18.0/account_move_line_mrp_info)
(which links `account.move.line` records to their manufacturing order through
`mrp_production_id`). It improves the existing button so that it is:

- **Visible to accounting users** (`account.group_account_user`) — the upstream
  button is hidden behind developer mode (`base.group_no_one`).
- **Equipped with a counter** showing how many journal items the production
  generated.
- **Showing both sides** — the action expands each linked entry to its full set
  of lines, so both the debit and the credit legs of every valuation/labour
  entry are displayed.

## Usage

Open any manufacturing order that has already produced valuation entries. In the
button box (top-right) you will see **Journal Items** with the line count. Click
it to review the debit/credit movements in the standard journal items list view,
grouped by manufacturing order.

## Dependencies

- `account_move_line_mrp_info` (OCA/manufacture)
