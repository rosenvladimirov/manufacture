# Changelog

## 18.0.1.0.0 (2026-06-25)

### Added
- Smart button "Journal Items" on the manufacturing order form, visible to
  accounting users (`account.group_account_user`) instead of only in developer
  mode.
- Counter on the button showing the number of related journal items
  (`account_move_line_count`).
- `action_view_account_move_lines` opens the debit/credit journal items of the
  accounting entries generated by the manufacturing order in the standard
  `account.view_move_line_tree` list view, grouped by manufacturing order.
