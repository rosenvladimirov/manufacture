======================
Mrp Workorder Bufering
======================

Add buffer for final product and conponets to possible to record production after finish registration on all.

Installation
============

To install this module, you need to:

#. Goto on applications menu, find the module and install it.

Configuration
=============

To configure this module, you need to:

#. Noting to do.


Usage
=====

To use this module, you need to:

#. Go to on work order to use buffering click on button buffering and order is move in buffered state.
When finish adding the components and final products, push on Done.
